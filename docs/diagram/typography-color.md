# 字体与颜色

目标：**在 100% 缩放下能读，在黑白打印下还能分辨，在深色模式下不崩。**

## 1. 字号阶梯

| 用途 | 字号 | 备注 |
|---|---|---|
| 页面标题 | 18–20，加粗 | 一个页面一个 |
| 容器标题 | 14，加粗 | `startSize=24` 够放 |
| 节点正文 | 12–14 | 默认 12；中文密排用 13 |
| 边标签 | 11–12 | 不要小于 11 |
| 图注/注释 | 11 | 再小就只能打印看 |

规则：

- 不小于 11；确实放不下就拆节点，不要缩字。
- 一页最多三个字号层级。
- 中文用系统字体（`Helvetica`/`Microsoft YaHei` 回退）；英文可用 `Inter`，但要带 `fontSource` 的编码 URL，离线环境会退化。

## 2. 颜色角色

| 角色 | fill | stroke | 用途 |
|---|---|---|---|
| 步骤 | `#EEF4FF` | `#9DB8F2` | 普通处理 |
| 判断 | `#FFF6E0` | `#E8C36A` | 分支 |
| 开始/结束 | `#E7F6EC` | `#8BCB9F` | 入口、成功终点 |
| 等待/重试 | `#FFF0E5` | `#F0B48A` | 异步、重试 |
| 错误/取消 | `#FDECEC` | `#EBA3A3` | 失败、回滚 |
| 数据/存储 | `#F3EEFF` | `#B9A6F0` | 库、队列、文件 |
| 外部系统 | `#F2F4F7` | `#B8C0CC` | 第三方、用户 |
| 容器 | `#F7F8FA` | `#D5DAE1` | 边界 |
| 注释 | `#FFF9DB` | `#E9D58A` | 说明 |
| 文字 | — | — | `#1B1F24` |

规则：

- 一张图 ≤ 4 种角色色（加容器灰与注释黄不算）。
- 填充浅、描边深、文字近黑；不要反过来。
- 同角色同色，跨页也保持一致。

## 3. 对比度

- 正文与填充对比 ≥ 4.5:1（WCAG AA）。
- 上面给的配色均满足；自定义深色填充时把文字改成白色。
- 不要用颜色作为**唯一**区分手段：分支同时用标签（是/否）、线型或位置。

## 4. 线型语义

| 线型 | 含义 | 必须 |
|---|---|---|
| 实线 | 主路径、同步调用 | — |
| 虚线 | 异步、补偿、可选 | 图例说明 |
| 粗线 | 强调（少用） | 图例说明 |
| 不同颜色边 | 不同通道/环境 | 图例说明 |

一张图里虚线只能有一个含义。

## 5. 深色模式

```xml
<mxGraphModel background="#0F172A" adaptiveColors="none">
```

| 角色 | fill | stroke | 文字 |
|---|---|---|---|
| 步骤 | `#1E293B` | `#60A5FA` | `#F1F5F9` |
| 判断 | `#1E293B` | `#FBBF24` | `#F1F5F9` |
| 成功 | `#064E3B` | `#34D399` | `#F1F5F9` |
| 错误 | `#450A0A` | `#F87171` | `#F1F5F9` |
| 边 | — | `#94A3B8` | `#E2E8F0` |

不加 `adaptiveColors="none"` 时，draw.io 会按反色规则自动适配；自定义深色主题必须关掉自动适配，否则颜色会被二次变换。

## 6. 打印

- 黑白打印时，靠**明度差**和线型区分，不要靠色相。
- 容器填充用 `#FFFFFF` 或极浅灰，避免整块黑。
- 导出 PDF 前把背景设为白色（`background="#FFFFFF"`）。

## 7. 字体在别的机器上

- `fontSource` 指向 Google Fonts 的编码 URL；离线环境加载失败会回退。
- 交付给外部时优先系统字体，避免"我这有、他那没有"。
- 中文不要用纯英文字体名，容易出现方框。

## 8. 检查表

- [ ] 最小字号 ≥ 11
- [ ] 字号层级 ≤ 3
- [ ] 角色色 ≤ 4，且同角色同色
- [ ] 文字对比度 ≥ 4.5:1
- [ ] 虚线只有一个含义，且有图例
- [ ] 黑白打印仍能区分主次
- [ ] 深色模式下文字没有变成深色填充上的深色
