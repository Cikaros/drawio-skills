### V-03 畸形 XML 仍返回 URL

调用内容故意缺少 `</mxCell>`：

```xml
<mxGraphModel><root><mxCell id="0"/><mxCell id="1" parent="0"/><mxCell id="a" value="unclosed" vertex="1" parent="1"><mxGeometry .../></root></mxGraphModel>
```

返回：同样格式的 `Draw.io Editor URL` + `The diagram has been opened in your default browser.`，无错误。

结论：不能把"返回 URL"当成"图可用"。


随后 `get_page(path, 1)` 返回新内容；第二页整体被替换（旧 `t1` 被新 `t1` 取代）。

### V-10 压缩页格式

用 `deflateRaw(encodeURIComponent(xml))` → **再 URI 编码** base64 写入文件，`get_page` 报：

```text
Error: Failed to decompress page content: invalid bit length repeat
```

改为**纯 base64**（不 URI 编码）后，`get_page` 正常返回 XML。

结论：文件内 payload 是纯 base64；URI 编码只用于 URL。

### 结论

- 无法取得权威 stencil style 列表，也未能逐一验证库内名称。
- 因此不写任何未验证的 stencil 名称，改用三级策略：
  - Tier A：MCP XML 参考明确给出或本仓库示例已验证；
  - Tier B：mxGraph 核心 `shape=` 关键字，写错退化为矩形，首次必须预览；
  - Tier C：品牌/行业图标只能由 `search_shapes` 返回，离线时降级。
- 新增 `examples/06-shape-smoke-test.drawio`（38 个形状，其中 33 个 Tier B），供一次目视确认；`test/reference-contract.test.mjs` 保证该文件 lint-clean 且被 SKILL 引用。
- 场景矩阵 68 条仅使用图种语义与已验证元素，不依赖未验证 stencil。
