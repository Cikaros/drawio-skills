# 软件工程图景：场景 × 图种 × 元素

这是选型主表。用法：**先按场景查行，再按"推荐图"取骨架，最后按 `shape-libraries.md` 选元素。**

## 0. 选型五问

按顺序回答，答案决定图种：

1. **读者要做什么决定？** 批准预算 / 写代码 / 排障 / 交接 / 合规。
2. **讲结构还是讲行为？** 结构（谁依赖谁）→ 架构/类/ER；行为（先后、分支）→ 时序/状态/流程。
3. **关注边界还是交互？** 边界 → C4/部署/泳道；交互 → 时序/DFD/事件流。
4. **要精确契约还是概念共识？** 契约 → 类图/ER/API 表；共识 → 上下文/概念图/思维导图。
5. **15 个节点讲得完吗？** 讲不完就拆页或分层，不要缩字号。

五问之后仍不确定：**选能回答第 1 问的最简单图种**，而不是最全的。

## 1. 五类视图

| 视图 | 回答 | 主图种 | 元素组 |
|---|---|---|---|
| 上下文/范围 | 系统在哪、和谁交互 | 上下文图、用例图、思维导图 | 通用 + 软件 |
| 结构 | 由什么组成、怎么依赖 | 分层、C4、组件、类、ER、部署 | 软件 + 网络 |
| 行为 | 按什么顺序、什么状态 | 时序、状态机、活动、BPMN | 软件 + 流程图 |
| 数据 | 数据从哪来到哪去 | DFD、ER、血缘、管道 | 基本 + 软件 |
| 运营/决策 | 谁负责、如何取舍 | 泳道、价值流、象限、鱼骨 | 商务 + 通用 |

矩阵未列出的场景，按五问 + 五类视图推导：先确定视图，再选该视图里**能回答第一个问题的最简单图种**；不要发明新图种。非软件领域（网络运维、P&ID、电气、平面图）同样按五问选图种，元素按 `shape-libraries.md` 选，品牌/行业图标只能走 `search_shapes`。

## 3. 交付套餐

单张图很少够用。常见组合：

| 交付 | 组合 | 说明 |
|---|---|---|
| 架构评审包 | A1 + B3 + B6 + B8 | 上下文 → 容器 → 关键调用 → 部署 |
| 新人 onboarding | A1 + B2 + A7 + F5 | 系统在哪 → 服务全貌 → 术语 → 出事找谁 |
| 故障复盘 | I3 + F5 + 时间线 | 根因 → 响应过程 → 时间轴 |
| 数据平台 | D5 + D3 + D4 + D2 | 分层 → 血缘 → 管道 → 表结构 |
| 安全评审 | G4 + G5 + G6 + B8 | 数据流/边界 → 攻击树 → 权限 → 部署 |
| 上线准备 | F1 + F2 + F3 + F6 | 管道 → 环境 → 发布 → SLO |
| 需求对齐 | A1 + A2 + A5 + A6 | 上下文 → 用例 → 流程 → 规则 |

套餐原则：**每张图只回答一个问题**；页名写问题，不写图种（`订单如何支付` 而非 `时序图2`）。

## 4. 反模式

| 反模式 | 为什么错 | 换成 |
|---|---|---|
| 用类图讲部署 | 类没有节点/网络语义 | B8 部署图 |
| 用 ER 讲消息流 | ER 没有时序 | C5 时序图 / B5 事件流 |
| 用架构图讲分支逻辑 | 读者找不到条件 | A5 流程 / C6 状态机 |
| 用泳道讲类结构 | 泳道是责任主体，不是类型 | C1 类图 |
| 用思维导图当规范 | 无法检索、无法验收 | 文档 + 一张总览图 |
| 一张图塞下所有视图 | 主路径被淹没 | 套餐拆分 |
| 用品牌图标代替协议说明 | 图标不表达契约 | 图标 + 标签 + 图例 |
| 用 3D/阴影强调重点 | 视觉噪音 | 位置/粗细/颜色角色 |

## 5. 规模与拆分

| 节点数 | 处理 |
|---|---|
| ≤ 15 | 单页 |
| 16–25 | 简化标签；拆"总览 + 细节" |
| > 25 | 必须拆页；总览只留主路径 |

拆分顺序：总览 → 主流程 → 子系统/阶段 → 异常 → 附录。页名即导航。

## 6. 三条快速路径

- **"画个架构图"**：默认 B3（C4 Container）；读者是新人时加 A1；要讲调用再加 B6。
- **"接口怎么调"**：C8（端点表）+ C5（时序）；不要用类图代替契约。
- **"数据怎么流"**：B7（DFD）讲系统间；D3（血缘）讲表间；D4（管道）讲作业。

## 7. 与元素库的衔接

- 结构图（B/C/D1）→ 软件库 + 通用；容器用 `swimlane`，库用 `cylinder3`。
- 行为图（C5/C6/C7/E）→ 软件库 + 流程图；生命线用 `shape=umlLifeline`。
- 部署/网络（B8–B10）→ 网络库；品牌图标只能 `search_shapes`，离线降级。
- 组织/决策（H/I）→ 商务库 + 通用；矩阵用 `shape=table`，象限用轴 + 文本。
- 每个 Tier B/C 形状首次使用必须预览（见 `shape-libraries.md` 第 3–4 节）。
