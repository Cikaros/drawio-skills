# 评审清单

交付前逐项过。分三档：**阻断**（必须修）、**应修**（有理由才放过）、**建议**。

## A. 结构与文件

- [ ] **阻断** 文件能被 draw.io 打开（根节点、闭包、无注释）
- [ ] **阻断** `validate-drawio.mjs --strict` 零 error
- [ ] **阻断** 每条边有 source/target 与 `relative="1"` geometry
- [ ] **阻断** id 唯一；`0`/`1` 存在
- [ ] 应修 边挂在最内层公共容器（`EDGE004`）
- [ ] 应修 页 id/页名唯一；页名不带 `/`
- [ ] 建议 单页节点 ≤ 25

## B. 布局

- [ ] **阻断** 没有重叠节点（`LAYOUT001`）
- [ ] **阻断** 子元素在容器内（`LAYOUT002`）
- [ ] 应修 子元素不压容器标题（`LAYOUT003`）
- [ ] 应修 主路径单向，不回头
- [ ] **阻断** 没有边共享长段或原路折返（`EDGE005`）
- [ ] **阻断** 边不穿过无关方块（`EDGE006`）
- [ ] 应修 交叉 ≤ 2；同一形状的出入边使用不同端口
- [ ] 建议 同列/同行对齐，间距统一
- [ ] 建议 标题、图例不压图体

## C. 文字

- [ ] **阻断** 含 HTML 的 label 有 `html=1` 且已转义
- [ ] **阻断** 没有零宽/零高节点
- [ ] 应修 最小字号 ≥ 11
- [ ] 应修 标签 ≤ 3 行，每行 ≤ 12 汉字
- [ ] 应修 术语全图一致
- [ ] 建议 边标签 ≤ 3 词
- [ ] 建议 图注说明结论，而不是复述节点

## D. 视觉

- [ ] **阻断** 一套图一个主题
- [ ] 应修 角色色 ≤ 4，同角色同色
- [ ] 应修 虚线只有一个含义，且有图例
- [ ] 应修 黑白打印仍能读
- [ ] 建议 文字对比度 ≥ 4.5:1
- [ ] 建议 深色模式单独验证

## E. 内容

- [ ] **阻断** 图能回答开头的那个问题
- [ ] **阻断** 每个判断的两条分支都有去向
- [ ] 应修 每个异常有处理或明确"不处理"
- [ ] 应修 没有孤立节点
- [ ] 建议 数据、名称与源文档一致
- [ ] 建议 复杂图附文字版

## F. 交付

- [ ] **阻断** 交付的是 `.drawio` 源文件（不是只有 PNG）
- [ ] 应修 预览过关键页；未预览则明确声明
- [ ] 应修 文件路径、页数、节点/边规模写进说明
- [ ] 建议 导出 SVG 或 2x PNG 供快速查看
- [ ] 建议 多页文件的页序符合阅读顺序

## 快速命令

```bash
node scripts/validate-drawio.mjs --strict path/to/file.drawio
node --test
npm run check
```
