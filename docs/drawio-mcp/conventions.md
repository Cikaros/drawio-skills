# 约定

分两类：**硬规则**（违反即错误，lint 会拦）与**项目约定**（可覆盖，但要全图一致）。

## 1. 硬规则

| 规则 | 原因 |
|---|---|
| 每条边都有 `<mxGeometry relative="1" as="geometry"/>` | 否则不渲染 |
| 边挂最内层公共容器，跨容器挂 `parent="1"` | 否则布局引擎画错帧 |
| `id` 在文件内唯一 | 重复 id 会导致引用错乱 |
| 必须有 `id="0"`（根）与 `id="1"`（默认层） | 缺了编辑器无法加载 |
| 含 HTML 的 label 必须 `html=1` 且已转义 | 否则显示源码 |
| 换行用 `<br>` 或 `&#xa;`，不用字面 `\n` | 否则显示 `\n` |
| 禁止 XML 注释 | 解析器不接受 |
| 顶点宽高 > 0 | 零尺寸不可见 |
| 子元素坐标相对父容器，且让开 `startSize` | 否则跑出容器/压住标题 |
| 页面 id 唯一，页名不带 `/` | `/` 会被规范化 |

## 2. 命名

### 页面

- 用**读者视角**命名：`总览`、`下单流程`、`部署拓扑`，不要 `Page-1`。
- 一页一个主题；超过约 25 个节点就拆页，用页名做导航。
- id 用短横线小写：`overview`、`order-flow`、`deploy-topology`。

### 节点 id

- 稳定、可读、可预测：`n1…n9`（节点）、`d1…d9`（判断）、`e1…e9`（边）、`lane1`、`svc`、`db`。
- 改图沿用旧 id；不要每次重建都换 id，否则外部引用失效。
- 不要用随机 UUID：不可读，diff 噪音大。

### 标签

- 动作用**动词短语**（`提交订单`、`校验库存`），状态用**名词/形容词**（`已支付`、`待发货`）。
- 一条标签 ≤ 3 行，每行 ≤ 12 个汉字；超了就拆节点或改成注释。
- 同一概念全图同名：不要一处"用户"一处"客户"。

## 3. 几何

- 网格：`x = col*180+40`，`y = row*120+40`。
- 尺寸：矩形 140×60，菱形 160×90，椭圆 140×60，圆柱 110×70。
- 一个节点占一个网格单元；不要靠"微调 3px"解决重叠。
- 同层节点左对齐或上对齐；跨层保持同一列。
- 容器内边距：左/上 ≥ 20；泳道子元素从 `startSize` 之后再留 10。

## 4. 样式

- 一套图一个主题，来自 `docs/diagram/typography-color.md`。
- 颜色按**角色**分配，最多 4 种角色（步骤、判断、异常、外部）。
- 字号：标题 18–20，节点 12–14，注释 11；不要小于 11。
- 边：流程用 `orthogonalEdgeStyle;rounded=1`；同类边同一线型。
- 虚线只表达一种含义（异步/补偿/可选），并在图例里说明。

## 5. 元数据

需要机器可读信息时用 `<object>`：

```xml
<object id="svc" label="订单服务" tags="core v1" owner="平台组" placeholders="1">
  <mxCell style="rounded=1;whiteSpace=wrap;html=1;" vertex="1" parent="1">
    <mxGeometry x="40" y="40" width="160" height="70" as="geometry"/>
  </mxCell>
</object>
```

- `tags` 用空格分隔，全仓库统一词表（如 `core`、`deprecated`、`v2`）。
- 自定义属性名用短横线小写：`owner`、`sla`、`repo`。
- 不要把大段说明塞进属性；说明放节点文字或注释层。

## 6. 层

- 默认层 `id="1"` 放主体。
- 注释/图例单独一层（`parent="0"`），便于整层隐藏。
- 层名用读者能懂的词：`注释`、`安全区`、`历史版本`。
- 不要用层做"页面分组"——那是多页的职责。

## 7. 多页文件

- 一个文件 = 一个系统/一个交付物；页 = 视图。
- 页顺序按阅读顺序：总览 → 主流程 → 细节 → 附录。
- 页间术语、颜色、编号一致。
- 新增页时保持既有页 id 不变。

## 8. 提交到仓库

- 源文件提交 `.drawio`，不要只提交 PNG。
- 导出图放 `docs/assets/` 或交付目录，命名 `图名@2x.png`。
- 二进制导出物与源文件同一次提交，避免"图与源不一致"。
